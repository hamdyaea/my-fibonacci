# Fibonacci in Python 3

Developer: **Hamdy Abou El Anein**  
Contact: **info@daylightlinux.ch**  
License: GPL-3.0-only (see LICENSE).

This project provides a reusable infinite Fibonacci generator and a command-line interface. The sequence begins with 1, 1.

```sh
python3 fibonacci.py --count 20
python3 -m unittest discover -s tests -v
```

The graphical `fibonacci-draw.py` demonstration requires matplotlib and remains separate from the CLI. The historical implementation is preserved on the [old branch](https://github.com/hamdyaea/my-fibonacci/tree/old).
